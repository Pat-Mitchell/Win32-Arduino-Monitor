# LRC Resonance Detector

This project will be revisited at a later time. The data observed by the arduino is inconsistant with what should be happening. A0 is reading a peak early in the frequency sweep and diminishing as if it were reading a low-pass instead of a band-pass signal. A standard multimeter does indicate that the wiring is correct and there is an increasing and decreasing voltage as the frequency approaches and leave resonance.

An oscilloscope would be more useful for debugging the circuit and verify that results consistent with theory are obtainable. Unfortunately, I don't have an oscilloscope at this point in time.
